这里记录甘露影视（LG Video）各版本的更新内容。想看某一版的完整说明，点导航栏「下载」进各发布页即可。

## v1.1.0

- 应用更名为「甘露影视（LG Video）」：界面标题、关于页、托盘全面换新品牌
- 开源地址与更新渠道切换：全球官方 GitHub 与国内镜像 Gitee 已切换到新仓库 LGVideo
- 纯白主题下侧栏导航文字对比度修复，侧栏文字清晰可读
- 已有设置、影视库与播放进度不受影响，升级后照常使用

## v1.0.0

- 全新视觉：紫金黑主题默认开启液态玻璃质感（磨砂玻璃 + 折射 + 七彩色散 + 金色边缘流光），另提供自定义、纯白、纯黑共 4 套主题
- 解析&浏览器：多标签同时浏览网页，网页视频一键解析直接播放
- 本地视频：添加本地目录自动扫描，常见视频格式直接点播
- 我的影视：自建影视库，自定义名称、简介、封面与集数，每集可填在线链接或本地文件
- 精雕播放器：进度与缓冲、倍速、A-B 循环、上下集切换、全屏、快捷键、进度记忆与自动续播
- 双渠道更新：全球官方 GitHub 与国内镜像 Gitee，可手动检查更新
- 托盘常驻：关闭窗口最小化到托盘，重复启动自动唤起已有窗口
- Windows 提供普通版与 Win7 兼容版
