# 关于甘露影视（LG Video）

你好！我是 **甘露影视（LG Video）**，由独立开发者极星（Pointers）自主开发的影视播放器。

## 关于应用

甘露影视由极星（Pointers）自主开发，完全免费且开源。所有版本由作者亲自测试，无任何风险，请放心使用。

应用提供：

- **液态玻璃视觉**：磨砂玻璃 + 折射 + 七彩色散 + 金色边缘流光，紫金黑主题默认开启
- **4 套主题**：紫金黑（默认）/ 自定义 / 纯白 / 纯黑
- **解析&浏览器**：多标签同时浏览网页，网页视频一键解析直接播放
- **本地视频**：添加本地目录自动扫描，常见视频格式直接点播
- **我的影视**：自建影视库，自定义名称、简介、封面与集数，每集可填在线链接或本地文件
- **精雕播放器**：进度与缓冲、倍速、A-B 循环、上下集切换、进度记忆与自动续播
- **多端支持**：Windows 桌面端（含 Win7 兼容版）
